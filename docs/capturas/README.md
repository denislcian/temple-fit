# Capturas de pantalla

Guarda aquí las capturas que enlaza el README principal (las herramientas
headless no esperan a IndexedDB, así que se hacen a mano en 2 minutos):

1. `npm run dev` y abre http://localhost:5173
2. Registra un entrenamiento de ejemplo y genera un plan en Rutinas.
3. Captura (Win+Mayús+S) y guarda como:
   - `entrenar.png` — vista Entrenar con un entrenamiento en curso (tema oscuro)
   - `progreso.png` — vista Progreso con gráficas
   - `rutinas.png` — vista Rutinas con un plan generado
   - `movil.png` — DevTools en modo móvil (375px), cualquier vista
